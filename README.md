# VALORANT カスタムチーム分けツール

VALORANTのカスタムゲームの参加者とランク・（ロール）を入力することでチーム決めを行うことができるツールです。

---

## 使い方
1. 空きスロット　または　+プレイヤーを追加　から　参加するプレイヤーの名前とランクを入力してください。
  - ランクはランクアイコンをクリックすることで変更することができます。

2. ２人以上登録し、「チーム分けを行う」をクリックすることで、レート計算に基づき、最適な組み合わせが表示されます。
3. 結果をDiscordなどに簡単に共有できるように、テキストでコピーできる機能があります。「組み合わせをコピーする」を押して、そのままDiscordに貼り付けてください。
 - マークダウンと絵文字を使用しています。マークダウンや絵文字ができない環境では、<":blue_circle:">のように正しく表示されない可能性があります。（読みづらいですが、認識できる範囲だと思います。）

## 機能と特徴

- **候補パターンの切り替え**機能があります。
  - チーム分け実行後、候補案（最大8案）が（`① 差○pt` 〜 `⑧ 差○pt`）という形で表示されます。クリックすることでチーム分けを切り替えられます。
  - 「全パターン比較」をクリックすることで更に最大１６案の一覧が見れます。各案のプレビューを確認して、「この案を適用する」をクリックすることで適応されます。

- 特定のプレイヤーがこのロールしか使えないという制限がある場合は、 **ロールバッジをクリックしてロールを選択することで**、組み合わせを行う際に、配慮されます。ただし、同じロールが二人以上いない（被りがいない）場合は、組み合わせ時の配慮事項に含まれません。原則として、同じロールが二人の場合は、それぞれ違うチームに配置されます。
- チーム内でここのデュオは同じチームである必要がある場合や、主将が決まっていて、その二人は違うチームにすることが決まっている場合などは、**鍵アイコン（`🔓 / 🔒`）**をクリックしてください。その人は原則として組み合わせ時に配慮されます。
- プレイヤーごとについている歯車をクリックすると実力補正を行うことができます。
  - 前試合の対戦MVPに補正をかけられるほか、 カスタム補正を(-500pt 〜 +500pt)の範囲内で行うことができます。基本的には、前回の試合の貢献度ボーナス (ハンデ調整)を使用することになると思います。
- プレイヤーが消す場合は　×　を押してください。

- **選考基準の切り替え**機能があります。: アクションバーから切り替えることが可能です。
  - **バランス重視（デフォルト）** : ロール差とランク差のバランスを取って、最もレート差が小さい案を上位選出。
  - **ロール差重視**: ロール構成の均等を優先に決めます。（片方のチームに3名以上集中する構成は原則組み合わせから除外されています。）
  - **ランク差重視**: チーム間のランク差を優先に決めます。

- 人数不足の際（１０人以下）、観戦者から補充するか今の人数のままでチーム分けを行うか選択することができます。


- **攻守交代**:機能があります。 「攻守交代」ボタン（水色ボタン）でアタッカーとディフェンダーのメンバーを入れ替えられます。

### フッターの機能について

- **テスト用**: デバック用・お試し用です。組み合わせ例を確認できます。

- **一括登録**: プレイヤー名やランクが書かれたテキストを入力して一括で登録することができます。

- **保存**: 現在のプレイヤー構成をテキスト形式で出力することができます。「📋 コピーする」をクリックして保存ができます。そのデータを「一括登録」にそのまま貼り付けることで簡単に復元することが可能です。
- **消去**: 全プレイヤーを消去します。

- ランクに基づくレート値は下記のとおりです。

| ランク帯 | レート値 |
|---|---|---|
| レディアント | 3000 |
| イモータル 3 | 2700 |
| イモータル 2 | 2500 |
| イモータル 1 | 2300 ||
| アセンダント 3 | 2100 ||
| アセンダント 2 | 2000 |
| アセンダント 1 | 1900 |
| ダイヤモンド 1〜3 | 1600 / 1700 / 1800 |
| プラチナ 1〜3 | 1300 / 1400 / 1500 |
| ゴールド 1〜3 | 1000 / 1100 / 1200 |
| シルバー 1〜3 | 700 / 800 / 900 |
| ブロンズ 1〜3 | 400 / 500 / 600 |
| アイアン 1〜3 | 100 / 200 / 300 |
| アンランク | 1000 |
